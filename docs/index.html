What you can do

Your content, easier to explore.

01

Connect your provider

Sign in to an Xtream-compatible service over HTTP or HTTPS. Optionally remember a connection with encrypted storage on your device using Android Keystore.

02

Find your next watch

Browse live TV, movie categories and series. Search across all movies, explore details, and open seasons and episodes from your provider.

03

Play on Android

Watch using Media3 playback with immersive fullscreen, buffering feedback, retry and rotation continuity. Android 8.0 or later is required.

The interface supports ten languages, including English and Italian. Android TV, watch-progress resume, next-episode playback and a full TV guide are planned. Read the development roadmap for the current scope.

Get started

Bring your own
Xtream-compatible provider.

IPTV Receiver does not include an IPTV subscription, channels, films or series. You need your own provider account and permission to access its content.

  1. Open the Android project

    Clone the repository and follow the Android Studio and SDK requirements in the build instructions.

  2. Run on a phone or tablet

    Build the app locally for Android 8.0 or later. This is a development baseline; production signing and store publication are still pending.

  3. Sign in inside the app

    Enter your provider’s HTTP or HTTPS server address, username and password. Keep real account details out of GitHub, screenshots and bug reports.

A few useful answers

About IPTV Receiver

Does IPTV Receiver include channels or a subscription?

No. It is a client for an existing Xtream-compatible provider. It does not supply, sell or bundle content or subscriptions.

Can I download it from Google Play?

Not yet. The repository contains the source code and Google Play preparation materials. You can build a development version using the repository instructions.

Does it support Android TV?

The current app is designed for Android phones and tablets. A dedicated Android TV interface is planned and is not implemented yet.

Where can I find technical details?

Start with the architecture guide, verification report and security policy.
