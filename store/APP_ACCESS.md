# Reviewer access template

Enter the final values directly in Play Console's private App access section. Never add credentials to this repository.

1. Open IPTV Receiver. The interface follows the device language; use the Language menu to select English if needed.
2. Enter the dedicated review connection name, HTTPS provider base URL, username and password supplied privately by the publisher.
3. Tap Connect. Choose Live TV, Movies or Series, then a category. Select a movie and Play, or a series, season and episode.
4. Rotate during playback or use the fullscreen control. Back exits fullscreen before leaving the player.
5. Use Sign out to remove the locally remembered connection.

The publisher must provide a stable, non-expiring review account with legally cleared sample media, accessible from Google's review locations, without OTP, payment or geographic restrictions. Prefer HTTPS media/artwork so reviewers do not need HTTP compatibility. If any access restriction is unavoidable, explain it precisely in Console and verify the account regularly.

The debug screenshot fixture is not included in release builds and cannot provide review access. Do not publish a real user's account or use the user's private test subscription as a reviewer credential.
